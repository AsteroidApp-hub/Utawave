01시작하기·화면 보는 법

Utawave는 커버 영상·노래 투고를 위한 「녹음」에 특화된 DAW입니다. 어려운 설정은 최대한 줄이고, 반주 음원을 넣고, 녹음하고, 내보내는 흐름을 가장 빠르게 진행할 수 있도록 설계했습니다.

화면 구성

  • 상단(툴바)：재생 / 정지 / 녹음 버튼, 재생 위치의 시간 표시, 템포(BPM), 메트로놈과 루프 전환.
  • 왼쪽(TRACKS 패널)：트랙 목록. 각 트랙의 음량(Vol)·좌우(Pan)·잔향(Rev)·M 뮤트·S 솔로·R 녹음 암(arm)·I 입력 모니터링 등.
  • 중앙(타임라인)：녹음한 목소리나 가져온 음원이 「파형」으로 가로로 나열됩니다. 여기서 자르거나 옮길 수 있습니다.
  • 오른쪽(MASTER 패널)：곡 전체의 최종 음량과 미터. 접을 수 있습니다.
팁：대부분의 조작은 버튼과 키보드 양쪽에서 할 수 있습니다. 먼저 버튼으로 익숙해지고, 익숙해지면 단축키를 사용하면 작업이 빨라집니다.

02프로젝트의 기본

작업 내용은 「프로젝트」라는 단위로 저장합니다(파일 확장자는 .uta). 곡마다 프로젝트를 하나씩 만드는 식입니다.

새로 만들기·열기·저장

  • 새로 만들기：「파일」→「새 프로젝트...」
  • 열기：「파일」→「열기...」(Ctrl+O). 시작 화면의 「최근 사용한 프로젝트」에서도 열 수 있습니다.
  • 저장：Ctrl+S. 다른 이름으로 저장은 Ctrl+Shift+S.

자동 저장과 백업

일정 시간마다 자동으로 저장되고, 추가로 날짜·시간이 붙은 세대별 백업이 남습니다. 만약 앱이 종료되더라도, 다음에 같은 프로젝트를 열었을 때 복구할지 물어봅니다.

음원 파일은 프로젝트 안에 들어갑니다：가져온 음원이나 녹음은 프로젝트 폴더 내의 Audio 폴더에 복사됩니다. 프로젝트를 다른 사람에게 전달할 때는 폴더째로 전달하세요.

03반주 음원 가져오기

먼저 반주(오프보컬 / 반주 음원)를 불러옵니다.

  1. 화면 오른쪽 위의 IMPORT 버튼, 또는 「파일」→「오디오 불러오기...」(Ctrl+I)를 선택합니다. 또는 음원 파일을 타임라인에 드래그 앤 드롭. IMPORT 버튼은 오디오와 MIDI 둘 다 선택할 수 있으며, 확장자로 자동 판별합니다.
  2. 가져온 음원은 자동으로 곡의 맨 앞(0초)에 배치됩니다.

지원 형식：WAV / AIFF / MP3 / FLAC / Ogg 등 일반적인 형식을 지원합니다(macOS에서는 m4a / aac 등도 가능. 지원 형식은 OS에 따라 일부 다릅니다). 샘플레이트가 다른 파일은 자동으로 변환하여 불러옵니다.

음량도 자동으로 맞춥니다：가져올 때 음량(라우드니스)을 적정한 크기로 자동 조정합니다(설정에서 끌 수 있습니다).

04녹음 준비하기

  1. 트랙 추가：TRACKS 패널 왼쪽 아래의 + 버튼(또는 하단의 「+ Add Track」)에서 모노 / 스테레오를 선택합니다. 노래 녹음은 보통 모노로 충분합니다.
  2. 입력 선택：트랙의 「In:」에서 사용할 마이크(입력 채널)를 선택합니다.
  3. 녹음 암：녹음하려는 트랙의 R 버튼을 켭니다. 이렇게 하면 「이 트랙에 녹음한다」는 상태가 됩니다.
  4. 목소리 확인：I(입력 모니터)를 켜면 자신의 목소리가 돌아오고 미터도 움직입니다. 소리를 내서 미터가 흔들리는지 확인해 봅시다.
여러 트랙 동시 녹음：R을 여러 트랙에서 켜고 각각 다른 입력을 선택하면 동시에 여러 트랙에 녹음할 수 있습니다.
소리가 나지 않거나 입력이 나오지 않을 때는：툴바 오른쪽 위의 AUDIO 버튼을 눌러, 오디오 설정에서 사용할 오디오 기기(오디오 인터페이스)가 선택되어 있는지 확인하세요.

05템포(BPM)와 박자

곡의 템포(BPM)와 박자(4/4, 3/4 등)는 언제든지 변경할 수 있습니다. 곡 중간에 바꾸는 것도 가능합니다.

템포(BPM) 정하기

  • 숫자로 입력：툴바의 BPM 표시를 더블클릭하면 수치를 직접 입력할 수 있습니다.
  • 탭으로 정하기：TAP 버튼을 곡에 맞춰 두드리면 템포를 추정할 수 있습니다.
  • 자동으로 맞추기：가져온 음원을 우클릭 →「템포 검출」로 반주에서 BPM을 자동 추정할 수 있습니다.

곡 중간에 템포 바꾸기

타임라인 상단 눈금자에서 왼쪽 끝에 「◯◯ BPM」이라고 표시된 행(템포 행)을 사용합니다.

  • 템포 행에서 바꾸고 싶은 위치를 Ctrl+클릭하면 「BPM 설정」 대화상자가 열리고, 그 위치부터의 템포 변경을 삽입할 수 있습니다(곡 전체의 템포는 툴바의 BPM 표시에서).
  • 삽입한 템포 변경 마커는 드래그로 위치 이동, 우클릭 →「이 템포 변경 삭제」로 삭제할 수 있습니다.

박자 바꾸기(4/4 → 3/4 등)

템포 행 아래, 왼쪽 끝에 「Meter 4/4」라고 표시된 행(박자 행)을 사용합니다.

  • 박자 행을 Ctrl+클릭하면 박자 설정 대화상자가 열립니다. 마디 번호와 분자／분모를 선택하고 「삽입」을 누르면 그 마디부터 박자가 바뀝니다.
  • 마디 1을 지정하면 곡 전체의 박자를 변경할 수 있습니다.
  • 삽입한 박자 변경 마커는 드래그로 다른 마디로 이동, 우클릭 →「이 박자 변경 삭제」로 삭제할 수 있습니다.
MIDI 파일의 템포·박자를 사용하려면：MIDI를 불러올 때 「템포·박자도 가져오기」에 체크하면 파일에 기록된 템포·박자(중간 변화 포함)가 프로젝트에 반영됩니다.
주의：템포나 박자를 바꾸면 마디 눈금(그리드)과 메트로놈은 새 설정이 되지만, 이미 놓여 있는 음표나 파형의 위치·길이는 변하지 않습니다. 입력이나 녹음을 시작하기 전에 정해 두는 것을 권장합니다.

06메트로놈과 카운트인

  • 메트로놈：CLICK 버튼으로 클릭음 켜기 / 끄기. 클릭 전용 트랙에서 음량 등도 조정할 수 있습니다.
  • 카운트인：녹음 전에 몇 마디 카운트를 울릴지 설정할 수 있습니다(툴바의 C-IN 버튼).

07녹음하기

  1. 녹음하려는 트랙의 R이 켜져 있는지 확인합니다.
  2. 재생 위치를 녹음 시작 위치에 맞춥니다(룰러를 클릭, 또는 N / B로 한 마디씩 이동).
  3. R 키(또는 툴바의 녹음 버튼)로 녹음을 시작합니다. 카운트인 설정이 있으면 울린 뒤에 시작됩니다.
  4. 다시 한 번 R, 또는 Space로 정지합니다.

편리한 녹음 방법

  • 펀치인(punch-in)：재생하면서 다시 녹음하고 싶은 부분에서 R을 누르면 그 부분만 덮어쓰기 녹음할 수 있습니다(이음매는 자동으로 매끄럽게 처리됩니다).
  • 루프 녹음：L로 루프 구간을 반복 재생하면서 여러 테이크를 녹음할 수 있습니다.
  • 거슬러 올라가 확정：재생 중인 노래는 뒤에서 항상 캡처되고 있습니다. 「방금 게 좋았다」고 생각되면 Ctrl+Shift+R로 거슬러 올라가 녹음을 확정할 수 있습니다.

08테이크 관리

같은 위치에 다시 녹음하면 이전 테이크는 사라지지 않고 테이크 레인으로 자동으로 보관됩니다. 들어 비교하면서 좋은 테이크를 선택할 수 있습니다.

  • 트랙의 TList 버튼으로 테이크 레인의 표시 / 숨김을 전환합니다.
  • 각 테이크의 S(솔로)로 그 테이크만 들을 수 있습니다.
  • 채택하고 싶은 테이크의 ↑ 버튼(또는 Shift+↑)으로 그 테이크를 메인으로 올릴 수 있습니다.

09파형 편집하기

타임라인 위의 소리 덩어리를 「파형」이라고 부릅니다. 마우스로 직관적으로 편집할 수 있습니다.

페이드와 크로스페이드

  • 페이드인／아웃：범위를 선택하고 F. 시작과 끝을 매끄럽게 합니다.
  • 크로스페이드：두 파형의 겹치는／맞닿은 부분을 선택하고 X. 이음매의 「틱」하는 노이즈를 방지할 수 있습니다(우클릭 →「크로스페이드 그리기」로도 가능).

음량 조정

  • 파형별 음량：파형의 페이더로 올리고 내립니다. 파형 안에서 부분적으로 음량을 바꾸고 싶을 때는 음량 라인에 점을 찍어(브레이크포인트) 세밀하게 조정할 수 있습니다.
  • 무음 잘라내기：우클릭 →「무음 잘라내기」로 숨 쉬는 부분 등의 조용한 부분을 자동으로 제거할 수 있습니다.
표시 확대·축소：Ctrl＋마우스 휠로 가로 방향으로 줌, Shift+F로 곡 전체가 화면에 들어맞습니다.

10키 변경·템포 검출

  • 키(음정) 바꾸기：파형을 우클릭 →「키 변경...」으로 -6〜+6 반음 중에서 선택할 수 있습니다. 고품질 처리로 음질을 유지한 채 이조합니다. 결과는 새 파일로 저장되며, 같은 설정이면 다음번에는 바로 반영됩니다. 「0(원래 음정)」으로 원래대로 돌아갑니다.
  • 템포 알아보기：파형을 우클릭 →「템포 검출」로 반주의 BPM을 자동 추정합니다.

11이펙트(FX)

리버브나 컴프레서 등의 플러그인을 트랙이나 전체(마스터)에 추가할 수 있습니다.

FX 슬롯 열기

TRACKS 패널 왼쪽 아래의 FX 버튼을 누르면 각 트랙의 오른쪽에 이펙트용 슬롯(INS)이 표시됩니다. 다시 한 번 누르면 숨겨집니다.

  • 빈 슬롯을 클릭 → 사용하고 싶은 플러그인을 선택해 추가합니다.
  • 추가한 플러그인의 칩을 클릭하면 설정 화면이 열립니다.
  • Ctrl＋클릭으로 일시적으로 끄기(바이패스). 드래그로 순서 변경이나 다른 트랙으로 이동(Alt＋드래그로 복사).
플러그인이 나오지 않을 때는：「파일」→「플러그인 관리...」를 열고 스캔을 실행하세요. 설치된 플러그인이 목록에 표시됩니다.

리버브(잔향) 더하기

각 트랙의 Rev 슬라이더로 그 트랙에 잔향(리버브)을 더할 수 있습니다. 녹음 중의 「모니터링」에만 적용할 수도 있으며, 그 경우에도 녹음 파일에는 기록되지 않습니다.

12MIDI 불러오기·입력하기

MIDI 데이터(.mid 파일)를 불러와 가이드 멜로디나 화음, 반주로 활용할 수 있습니다. 손으로 직접 입력할 수도 있습니다.

MIDI 파일 불러오기

  1. 「파일」→「MIDI 불러오기...」를 선택하고 .mid 파일을 엽니다(타임라인으로의 드래그 앤 드롭도 가능).
  2. 「MIDI 불러오기」 대화상자에서 불러오고 싶은 트랙에 체크를 합니다(각 트랙의 채널이나 노트 수가 표시됩니다).
  3. 배치를 「맨 앞에 배치」 또는 「현재 재생 위치에 배치」 중에서 선택합니다. 필요에 따라 「템포·박자도 가져오기」, 「마커도 가져오기」에 체크합니다.
  4. 「불러오기」를 누르면 선택한 트랙이 MIDI 트랙으로 추가됩니다.
소리를 내려면：불러온 MIDI 트랙은 내장 음색으로 재생됩니다. 원하는 음원 플러그인을 끼우면 그 음색으로 울릴 수 있습니다(이펙트(FX)와 같은 방식으로 추가합니다).

손으로 입력하기(화음·가이드 만들기)

MIDI는 마우스만으로 처음부터 만들 수 있습니다. MIDI 키보드 등 외부 기기는 없어도 괜찮습니다.

순서 1：MIDI 트랙 추가하기

  • 화면 왼쪽 트랙 목록(TRACKS)의 왼쪽 아래에 있는 ＋ 버튼을 누르고, 메뉴에서 「MIDI 트랙 추가」를 선택합니다. 빈 MIDI 트랙이 추가됩니다.

순서 2：MIDI 클립(음표를 담는 상자) 만들기

  • 추가한 MIDI 트랙 행의 빈 곳을 더블클릭하면 1마디 길이의 MIDI 클립이 만들어집니다.
  • Alt+드래그로 드래그한 길이만큼의 클립을 만들 수도 있습니다.
  • 클립은 가운데를 드래그하면 이동, 좌우 끝을 드래그하면 길이를 바꿀 수 있습니다.

순서 3：피아노롤에서 음표 입력하기

  • MIDI 클립을 더블클릭하면 피아노롤(건반 편집 화면)이 열립니다.
  • 빈 곳을 더블클릭하면 음표가 추가됩니다. 상단의 연필 버튼(펜 도구·D 키)을 켜면 클릭으로 음표를 놓고 그대로 드래그해서 길이를 정할 수 있습니다.
  • 음표는 드래그로 이동, 좌우 끝 드래그로 길이 변경, Delete로 삭제. ↑ / ↓로 반음, Shift+↑ / Shift+↓로 옥타브 이동합니다.
  • 왼쪽 끝의 건반을 클릭하면 그 높이의 음을 미리 들어볼 수 있습니다.
MIDI 키보드가 있다면：환경설정의 「MIDI 입력」에서 키보드를 연결하면 건반을 눌러 바로 소리를 확인하거나, 실시간 녹음·스텝 입력으로 입력할 수도 있습니다(없어도 위의 순서로 모두 입력할 수 있습니다).
템포·박자를 바꾸려면：템포(BPM)와 박자의 변경 방법은 「템포(BPM)와 박자」 장에 정리되어 있습니다(MIDI를 불러올 때 「템포·박자도 가져오기」로 파일의 템포를 반영할 수도 있습니다).

13내보내기(WAV / MP3)

완성되면 음성 파일로 내보냅니다.

  1. 화면 오른쪽 위의 EXPORT 버튼, 또는 「파일」→「내보내기...」(Ctrl+E)를 엽니다.
  2. 형식(WAV / AIFF / MP3)과 범위(곡 전체／선택 범위／마디 범위)를 선택합니다.
  3. 믹스 전체를 한 파일로 할지, 트랙별(스템)로 나눌지를 선택해 내보냅니다.
음 깨짐 방지：내보낼 때 소리가 너무 크면 자동으로 조금 낮춰 깨짐을 방지합니다(설정에서 끌 수 있습니다).

14방송에서 사용하기(노래 방송)

Utawave의 소리(재생 중인 반주 + 마이크 리턴)를 OBS 등 방송 소프트웨어에 실어 노래 방송을 할 수 있습니다.

Windows에서 표준 드라이버(WASAPI)를 사용하는 경우

방송 소프트웨어의 "애플리케이션 오디오 캡처"에서 Utawave를 선택하기만 하면 소리를 잡을 수 있습니다. 별도의 설정은 필요 없습니다.

ASIO를 사용하는 경우(방송 미러 출력)

ASIO는 소리가 OS를 거치지 않는 구조라서 방송 소프트웨어가 그대로는 캡처할 수 없습니다. 방송 미러 출력을 사용하면 지금 들리는 소리를 다른 출력 장치로도 동시에 보내, 방송 소프트웨어가 잡을 수 있게 됩니다.

그 전에: 사용 중인 오디오 인터페이스에 "루프백" 기능이 있으면 그것으로 방송 소프트웨어에 소리를 보낼 수 있으므로 방송 미러 출력은 필요 없습니다(미러 출력은 루프백이 없는 기기를 위한 기능입니다).
  1. 도구 모음 오른쪽 위의 SETTING(환경설정) → "방송" → "방송 미러 출력 사용"을 켭니다.
  2. 미러 출력 장치는 평소에 듣지 않는 장치(PC 내장 스피커 단자, HDMI 모니터 등)를 선택하세요. 메인과 같은 장치를 고르면 소리가 이중으로 들리므로 피하세요. 미러 소리는 방송 소프트웨어가 잡기 위한 것으로, 실제로 들릴 필요는 없습니다.
  3. 방송 소프트웨어에서 "애플리케이션 오디오 캡처" 소스를 추가하고 Utawave를 선택합니다.
미러 장치에서 소리가 날 때: Windows의 "설정 → 시스템 → 소리 → 출력"에서 미러 장치를 열고 음량을 낮추세요. 방송 소프트웨어는 Utawave 소리를 직접 잡으므로 대부분의 환경에서는 스피커만 조용해지고 방송에 실리는 소리는 유지됩니다(혹시 몰라 방송 소프트웨어의 미터가 움직이는지 확인). 아무것도 연결하지 않은 HDMI 포트처럼 소리가 나지 않는 출력을 고르면 이 조작은 필요 없습니다.
영상과 소리가 어긋날 때: 방송 소프트웨어의 오디오 고급 속성에서 Utawave의 동기 오프셋을 조정하세요. 미러의 지연은 일정하므로 한 번만 맞추면 됩니다.

미러는 출력의 복사본이므로 녹음과 내보내기에는 영향이 없습니다. macOS에서는 시스템의 앱 오디오 캡처(macOS 13 이상, 방송 소프트웨어의 지원 필요)로 바로 잡을 수 있어 보통 미러 출력은 필요 없습니다.

애플리케이션 트랙 (브라우저나 노래방 앱의 소리를 방송에 섞기 — Windows)

브라우저나 노래방 앱의 소리를 트랙으로 가져와 노래와 함께 헤드폰과 방송으로 보낼 수 있습니다. 가상 케이블은 필요 없습니다. 가져온 소리는 녹음이나 내보내기에는 들어가지 않습니다 (방송·연습용 라이브 전용).

  1. 환경설정 →「방송」→ 「애플리케이션 트랙 사용」을 켭니다.
  2. 트랙 목록의 「+」→ 「애플리케이션 트랙 추가」.
  3. 트랙의 「앱 선택…」 버튼으로 소리를 재생 중인 앱 (브라우저 등) 을 선택합니다.
  4. 트랙의 음량과 팬으로 노래와의 밸런스를 조절합니다 (M 으로 음소거, INS 슬롯에 이펙트도 넣을 수 있습니다).
준비: Windows 의 기본 출력 장치 (앱이 소리를 내는 곳) 를 메인 오디오 인터페이스 이외 (내장 스피커 등) 로 설정하고 음량을 낮춰 두세요. 앱이 어느 장치로든 재생할 수 있으면 그 소리를 가져올 수 있습니다.
본체 스피커에서도 소리가 날 때: 헤드폰이나 오디오 인터페이스로 모니터링한 다음, "설정 → 시스템 → 소리 → 출력"에서 내장 스피커 장치 자체의 음량을 0으로 낮추세요. 장치 전체를 음소거해도 캡처는 멈추지 않고 소리는 그대로 방송에 실립니다. 참고: 볼륨 믹서에서 앱만 음소거하면 캡처도 함께 사라지므로 반드시 출력 장치 쪽에서 음소거하세요.
여러 앱을 섞으려면 앱마다 애플리케이션 트랙을 하나씩 추가하세요. 앱을 재시작해도 자동으로 다시 연결됩니다. macOS 에서는 브라우저 소리를 같은 장치로 그대로 들을 수 있으므로 이 기능이 없습니다.

17문제가 생겼을 때

「음성 파일을 찾을 수 없습니다」라고 표시된다

프로젝트가 참조하는 음원이 이동／삭제되었을 가능성이 있습니다. 원래 파일을 프로젝트 내의 Audio 폴더에 되돌려 놓으면 자동으로 복원됩니다.

이전 작업이 사라졌다／앱이 종료되었다

저장된 프로젝트를 다시 열면 더 새로운 백업이 있을 경우 복구를 물어봅니다. 「복구」를 선택하면 직전 상태로 되돌릴 수 있습니다.

마이크 소리가 녹음되지 않는다

  • OS의 마이크 사용 권한에서 Utawave가 허용되어 있는지 확인합니다.
  • 툴바 오른쪽 위의 AUDIO 버튼을 눌러, 오디오 설정에서 올바른 입력 기기와 채널이 선택되어 있는지 확인합니다.
  • 트랙의 R(녹음 암)이 켜져 있는지 확인합니다.

자신의 목소리가 늦게 들린다(모니터링 지연)

Windows에서 오디오 인터페이스를 사용하는 경우, 툴바 오른쪽 위의 AUDIO 버튼을 눌러 오디오 설정에서 드라이버 종류로 ASIO(인터페이스에 딸린 드라이버)를 선택하면 크게 개선됩니다. 함께 버퍼 크기를 작게 하면 지연이 줄어듭니다(너무 작게 해서 소리가 끊기는 경우에는 한 단계 되돌리세요).

녹음한 노래가 반주보다 늦게 들린다

Utawave는 녹음 시 기기의 지연(레이턴시)을 자동으로 보정합니다. 그래도 어긋나는 경우에는 툴바 오른쪽 위의 SETTING 버튼(환경설정)을 눌러 「녹음 플로우」에 있는 추가 녹음 보정 (ms)을 조금씩 늘려 조정하세요(+로 앞쪽으로 이동합니다).

플러그인이 목록에 나오지 않는다

「파일」→「플러그인 관리...」에서 「전체 다시 스캔」을 실행하세요. 설치 직후의 플러그인도 인식됩니다. 동작에 문제가 있는 플러그인은 스캔 시 자동으로 제외됩니다(앱은 멈추지 않습니다).
