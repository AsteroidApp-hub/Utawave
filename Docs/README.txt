========================================
 Utawave — 歌い手のための録音特化DAW
========================================

このたびは Utawave をダウンロードいただき、ありがとうございます。
無料で使えるマルチトラック録音ソフト（DAW）です。

----------------------------------------
 起動方法
----------------------------------------
[macOS]
 Utawave.app をダブルクリックで起動できます。
 （Apple の署名・公証（Notarization）済みのため、特別な操作は不要です）

[Windows]
 Utawave.exe を実行してください。
 初回に「Windows によって PC が保護されました」と表示された場合は、
 「詳細情報」→「実行」の順にクリックしてください（次回からは表示されません）。

----------------------------------------
 使い方
----------------------------------------
 同梱の「MANUAL.html」をダブルクリックすると、ブラウザで使い方ガイドが開きます。
 最新情報・詳しい使い方は公式サイトをご覧ください:
   https://utawave.com

----------------------------------------
 必要な環境
----------------------------------------
 ・macOS 11 (Big Sur) 以降（Apple Silicon / Intel）
 ・Windows 11 以降
