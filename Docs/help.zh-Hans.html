01开始之前·界面说明

Utawave 是一款专注于「录音」、面向翻唱·投稿用途的 DAW。它尽量省去复杂设置，让你以最短的流程完成导入伴奏音源、录音、导出这一套操作。

界面构成

  • 顶部（工具栏）：播放 / 停止 / 录音按钮、播放位置的时间显示、速度（BPM）、节拍器与循环的切换。
  • 左侧（TRACKS 面板）：轨道列表。每条轨道的音量（Vol）·左右声相（Pan）·混响（Rev）·M 静音·S 独奏·R 录音预备·I 输入监听等。
  • 中央（时间线）：录下的歌声与导入的音源会以「波形」的形式横向排列。可在此进行剪切、移动等操作。
  • 右侧（MASTER 面板）：整首曲子的最终音量与电平表。可折叠收起。
提示：大多数操作既可用按钮也可用键盘完成。建议先用按钮熟悉操作，熟练后再使用快捷键会让工作更快。

02项目基础

你的工作内容以「项目」为单位保存（文件扩展名为 .uta）。可以理解为每首曲子建立一个项目。

新建·打开·保存

  • 新建：「文件」→「新建项目...」
  • 打开：「文件」→「打开...」（Ctrl+O）。也可从启动画面的「最近使用的项目」中打开。
  • 保存：Ctrl+S。另存为是 Ctrl+Shift+S。

自动保存与备份

程序会每隔一段时间自动保存，并额外保留带日期时间的多代备份。万一程序意外退出，下次打开同一项目时会询问你是否恢复。

音源文件会保存在项目内部：导入的音频与录音会复制到项目文件夹内的 Audio 文件夹中。把项目交给他人时，请连同整个文件夹一起转交。

03导入伴奏音源

首先导入伴奏（off vocal / 伴奏音源）。

  1. 点击界面右上角的 IMPORT 按钮，或选择「文件」→「导入音频...」（Ctrl+I）。也可以把音源文件拖放到时间线上。IMPORT 按钮可同时选择音频和 MIDI，会根据扩展名自动判别。
  2. 导入的音源会自动放置到曲子开头（0 秒）处。

支持的格式：支持 WAV / AIFF / MP3 / FLAC / Ogg 等常见格式（macOS 上还可使用 m4a / aac 等。支持的格式因操作系统略有不同）。采样率不同的文件会自动转换后导入。

音量也会自动统一：导入时会把音量（响度）自动调整到一个合适的目标大小（可在设置中关闭）。

04准备录音

  1. 添加轨道：通过 TRACKS 面板左下方的 + 按钮（或底部的「+ Add Track」），选择单声道／立体声。录歌通常用单声道即可。
  2. 选择输入：在轨道的「In:」中选择要使用的麦克风（输入通道）。
  3. 录音预备：点亮要录音的轨道上的 R 按钮。这样就进入了「录到该轨道」的状态。
  4. 检查声音：点亮 I（输入监听）后，会听到自己的声音返回，电平表也会跟着动。出声确认电平表会摆动即可。
多轨同时录音：在多条轨道上点亮 R，并分别选择不同的输入，就能同时录到多条轨道。
没有声音、或找不到输入时：请点击工具栏右上角的 AUDIO 按钮，在音频设置中确认是否已选择要使用的音频设备（音频接口）。

05速度与节拍器

  • 速度（BPM）：双击工具栏的 BPM 显示，即可直接输入数值。
  • 用敲击确定：跟着曲子敲击 TAP 按钮，即可推算出速度。
  • 自动检测：右键点击导入的音源 →「检测速度」，即可从伴奏自动推算 BPM。
  • 节拍器：用 CLICK 按钮开关节拍声。还可在专用的节拍器轨道上调整音量等。
  • 预备拍（count-in）：可设置录音前先响几小节的预备拍（工具栏的 C-IN 按钮）。

06录音

  1. 确认要录音的轨道上 R 已点亮。
  2. 把播放位置对准到录音开始的位置（点击标尺，或用 N / B 每次移动一小节）。
  3. 按 R 键（或工具栏的录音按钮）开始录音。如设有预备拍，会先响完预备拍再开始。
  4. 再次按 R，或按 Space 停止。

实用的录音方式

  • 补录（punch-in）：在播放过程中，于想重录的位置按 R，即可只覆盖录制那一段（接缝处会自动平滑处理）。
  • 循环录音：用 L 让循环区间反复播放，可连续录制多个录音段。
  • 回溯确定：播放中的歌声会在后台持续被捕捉。当你觉得「刚才那次唱得好」时，可用 Ctrl+Shift+R 回溯并确定这段录音。

07录音段（take）管理

在同一位置重录时，之前的录音段不会被删除，而是自动转存到录音段轨道（take lane）。你可以反复试听、挑选满意的录音段。

  • 用轨道的 TList 按钮切换录音段轨道的显示 / 隐藏。
  • 用各录音段的 S（独奏）可只试听该录音段。
  • 用想采用的录音段上的 ↑ 按钮（或 Shift+↑），可将该录音段提升为主轨。

08编辑波形

时间线上的一段段声音称为「波形」。可以用鼠标直观地编辑。

淡入淡出与交叉淡化

  • 淡入／淡出：选中范围后按 F。让开头和结尾更平滑。
  • 交叉淡化：选中两段波形重叠／相接的部分后按 X。可防止接缝处「啪」的杂音（也可右键 →「绘制交叉淡化」）。

调整音量

  • 各段波形的音量：用波形的推子升降音量。若想在波形内部局部改变音量，可在音量线上添加点（断点）来精细调整。
  • 剪除静音：右键 →「剪除静音」，可自动去除换气等安静的部分。
放大·缩小显示：用 Ctrl＋鼠标滚轮可横向缩放，Shift+F 可让整首曲子刚好显示在画面内。

09变调·速度检测

  • 变调（改变音高）：右键点击波形 →「变调...」，可在 -6～+6 个半音之间选择。会以高品质处理在保持音质的同时移调。结果会保存为新文件，相同设置下次会立即套用。选择「0（原音高）」即可还原。
  • 检测速度：右键点击波形 →「检测速度」，可自动推算伴奏的 BPM。

10效果器（FX）

可以为单条轨道或整体（母线 master）添加混响、压缩器等插件。

打开 FX 插槽

按下 TRACKS 面板左下方的 FX 按钮，每条轨道的右侧就会显示效果器插槽（INS）。再按一次即可隐藏。

  • 点击空插槽 → 选择要用的插件并添加。
  • 点击已添加插件的标签，即可打开其设置界面。
  • Ctrl＋点击可临时关闭（旁通 bypass）。拖动可重新排序或移到其他轨道（Alt＋拖动为复制）。
插件没有出现时：打开「文件」→「管理插件...」，执行扫描。已安装的插件就会显示在列表中。

添加混响（残响）

用每条轨道的 Rev 滑块，可为该轨道添加混响（残响）。也可只对录音时的「返送（监听）」生效，即便如此也不会写入录音文件。

11导入·手动输入 MIDI

可以导入 MIDI 数据（.mid 文件），用作引导旋律、和声或伴奏。也可以手动输入。

导入 MIDI 文件

  1. 选择「文件」→「导入 MIDI...」，打开 .mid 文件（也可拖放到时间线上）。
  2. 在「导入 MIDI」对话框中，勾选想导入的轨道（会显示各轨道的通道与音符数量）。
  3. 放置方式可从「放置到开头」或「放置到当前播放位置」中选择。需要时可勾选「同时导入速度·拍号」「同时导入标记」。
  4. 按下「导入」，所选轨道便会作为 MIDI 轨道添加进来。
要发出声音的话：导入的 MIDI 轨道会以内置音色播放。若插入你喜欢的音源插件，就能用该音色发声（添加方式与效果器（FX）相同）。

手动输入（制作和声·引导）

  • 从添加轨道菜单中选择「添加 MIDI 轨道」。
  • 双击时间线会创建一个用于输入的区段，双击该区段即可打开钢琴卷帘（键盘编辑界面）。
  • 在钢琴卷帘中，双击空白处可添加音符，拖动可移动／改变长度，按 Delete 删除。用 ↑ / ↓ 升降半音。

12导出（WAV / MP3）

完成后导出为音频文件。

  1. 点击界面右上角的 EXPORT 按钮，或打开「文件」→「导出...」（Ctrl+E）。
  2. 选择格式（WAV / AIFF / MP3）与范围（整首曲子／选定范围／小节范围）。
  3. 选择把整个混音导出为 1 个文件，还是按轨道（分轨 stem）分别导出。
防止破音：导出时若声音过大，会自动稍微降低以防破音（可在设置中关闭）。

13右键·实用操作

Utawave 中有许多按钮上没有显示、需要通过右键菜单或双击才能完成的操作。这里整理了一些知道后能让工作轻松许多的内容。

在哪里右键？能做什么
波形（音频片段）变调 ／ 检测速度 ／ 调整响度（音量）／ 剪除静音 ／ 绘制交叉淡化
录音段轨道上的波形用「使用这个录音段」把该录音段采用为主轨（Lane 0）
轨道头部（轨道名附近）更改轨道颜色 ／ 再制轨道 ／ 删除轨道 ／ 调整响度

删除可以撤销：即使删除了轨道或片段，也可用 Ctrl+Z（Mac 为 ⌘Z）撤销。请放心尝试。

双击能做的事

双击哪里？能做什么
音量·Pan·Rev 滑块恢复为初始值（音量为 0dB，Pan 为居中，Rev 为 0）

记住会很方便的键位操作

操作作用
Alt＋点击（波形上）在该位置分割波形（剪切）
Ctrl＋点击（FX 标签）临时关闭该效果器（旁通 bypass）

15遇到问题时

提示「找不到音频文件」

项目所引用的音源可能已被移动／删除。把原文件放回项目内的 Audio 文件夹后会自动恢复。

上次的工作丢失了／程序退出了

重新打开已保存的项目时，如果存在更新的备份，会询问你是否恢复。选择「恢复」即可回到退出前的状态。

麦克风的声音录不进去

  • 确认操作系统的麦克风使用权限中已允许 Utawave。
  • 点击工具栏右上角的 AUDIO 按钮，在音频设置中确认已选择正确的输入设备和通道。
  • 确认轨道的 R（录音预备）已点亮。

自己的声音听起来有延迟（监听延迟）

在 Windows 上使用音频接口时，请点击工具栏右上角的 AUDIO 按钮，在音频设置中将驱动类型选为 ASIO（接口附带的驱动），会有大幅改善。同时把缓冲区大小调小也能减少延迟（如果调得太小导致声音断续，请往回调一档）。

录下的歌声听起来比伴奏慢

Utawave 在录音时会自动补偿设备的延迟（latency）。如果仍有偏差，请点击工具栏右上角的 SETTING 按钮（设置），在「录音流程」中把附加录音补偿 (ms) 一点点增大来调整（增大会使其向前移动）。

插件不出现在列表中

请在「文件」→「管理插件...」中执行「全部重新扫描」。刚安装的插件也会被识别。有问题的插件会在扫描时被自动排除（程序不会崩溃）。
