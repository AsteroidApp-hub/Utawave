01開始之前·畫面說明

Utawave 是一款專為翻唱投稿的「錄音」而設計的 DAW。盡量省去繁瑣的設定，讓你以最短路徑完成放入伴奏音源、錄音、再匯出的流程。

畫面構成

  • 上方（工具列）：播放 / 停止 / 錄音按鈕、播放位置的時間顯示、節拍（BPM）、節拍器與循環的切換。
  • 左側（TRACKS 面板）：軌道清單。可調整各軌道的音量（Vol）·左右（Pan）·殘響（Rev）·M 靜音·S 獨奏·R 錄音待命·I 輸入監聽等。
  • 中央（時間軸）：錄製的歌聲或匯入的音源會以「波形」橫向排列。可在此處剪切或移動。
  • 右側（MASTER 面板）：整首曲子的最終音量與電平表。可收合。
提示：大多數操作都可透過按鈕和鍵盤兩種方式進行。建議先用按鈕熟悉操作，上手後再使用快速鍵，作業會更快。

02專案的基本

作業內容會以「專案」為單位儲存（檔案副檔名為 .uta）。可想像成每首曲子建立一個專案。

新增·開啟·儲存

  • 新增：「檔案」→「新增專案...」
  • 開啟：「檔案」→「開啟...」（Ctrl+O）。也可從啟動畫面的「最近使用的專案」開啟。
  • 儲存：Ctrl+S。另存新檔為 Ctrl+Shift+S。

自動儲存與備份

系統會每隔一段時間自動儲存，並額外保留帶有日期時間的多代備份。萬一應用程式意外結束，下次開啟同一個專案時，會詢問你是否復原。

音源檔案會放入專案中：匯入的音源與錄音會複製到專案資料夾內的 Audio 資料夾。將專案交給他人時，請連同整個資料夾一起提供。

03匯入伴奏音源

首先匯入伴奏（無人聲 / 伴奏音源）。

  1. 點選畫面右上的 IMPORT 按鈕，或選擇「檔案」→「匯入音訊...」（Ctrl+I）。也可將音源檔案拖放到時間軸上。IMPORT 按鈕可選擇音訊或 MIDI，並依副檔名自動判別。
  2. 匯入的音源會自動配置到曲子的開頭（0 秒）。

支援格式：支援 WAV / AIFF / MP3 / FLAC / Ogg 等常見格式（macOS 上也支援 m4a / aac 等。支援格式會依作業系統略有不同）。取樣率不同的檔案會自動轉換後匯入。

音量也會自動對齊：匯入時會將音量（響度）自動調整到合適的大小（可在設定中關閉）。

04準備錄音

  1. 新增軌道：從 TRACKS 面板左下的 + 按鈕（或下方的「+ Add Track」）選擇單聲道／立體聲。錄唱通常使用單聲道即可。
  2. 選擇輸入：從軌道的「In:」選擇要使用的麥克風（輸入聲道）。
  3. 錄音待命：讓要錄音的軌道的 R 按鈕亮起。這樣就進入「錄到這個軌道」的狀態。
  4. 確認聲音：點亮 I（輸入監聽）後，就能聽到自己的聲音回送，電平表也會動。試著出聲確認電平表有擺動。
多軌同時錄音：讓多個軌道的 R 亮起，並各自選擇不同的輸入，即可同時錄到多個軌道。
沒有聲音、找不到輸入時：請在「檔案」→「環境設定」的音訊設定中，確認是否已選擇要使用的音訊裝置（音訊介面）。

05節拍與節拍器

  • 節拍（BPM）：雙擊工具列的 BPM 顯示，即可直接輸入數值。
  • 用敲擊設定：配合曲子敲擊 TAP 按鈕，即可推算出節拍。
  • 自動偵測：右鍵點選匯入的音源 →「偵測節拍」，即可從伴奏自動推算 BPM。
  • 節拍器：用 CLICK 按鈕開關節拍器聲音。透過節拍器專用軌道也可調整音量等。
  • 預備拍（count-in）：可設定錄音前要先響幾小節的預備拍（環境設定）。

06進行錄音

  1. 確認要錄音的軌道的 R 已亮起。
  2. 將播放位置對到錄音起始位置（點擊尺規，或用 N / B 一小節一小節移動）。
  3. 按 R 鍵（或工具列的錄音按鈕）開始錄音。若有設定預備拍，會先響起後才開始。
  4. 再按一次 R，或按 Space 停止。

便利的錄音方式

  • 補錄（punch-in）：一邊播放，在想重錄的地方按 R，即可只覆蓋錄製該段（接縫處會自動平順處理）。
  • 循環錄音：用 L 反覆播放循環範圍，即可錄製多個錄音片段。
  • 回溯確定：播放中的歌聲會在背景持續被擷取。當你覺得「剛剛那次很好」時，可用 Ctrl+Shift+R 回溯並確定錄音。

07錄音片段（take）的管理

在同一位置重錄時，先前的錄音片段不會消失，而是自動退避到錄音片段軌（take lane）。可聽比後選擇較好的片段。

  • 用軌道的 TList 按鈕切換錄音片段軌的顯示 / 隱藏。
  • 用各片段的 S（獨奏）只聽該片段。
  • 用想採用的片段上的 ↑ 按鈕（或 Shift+↑），即可將該片段提升為主軌。

08編輯波形

時間軸上的聲音區塊稱為「波形」。可用滑鼠直覺地編輯。

淡入淡出與交叉淡化

  • 淡入／淡出：選取範圍後按 F。讓開頭或結尾變得平順。
  • 交叉淡化：選取兩段波形重疊／相接的部分後按 X。可防止接縫處的爆音雜訊（也可透過右鍵 →「繪製交叉淡化」執行）。

音量的調整

  • 每段波形的音量：用波形的推桿上下調整。若想在波形內局部變更音量，可在音量線上加點（中斷點）做細部調整。
  • 切除靜音：右鍵 →「切除靜音」，即可自動移除換氣等安靜的部分。
放大·縮小顯示：用 Ctrl＋滑鼠滾輪可橫向縮放，按 Shift+F 可讓整首曲子顯示於畫面內。

09變調·節拍偵測

  • 變更音調（音高）：右鍵點選波形 →「變更音調...」，可從 -6～+6 半音中選擇。以高品質的處理在保持音質的情況下移調。結果會儲存為新檔案，相同設定下次會立即套用。選「0（原始音高）」即可回到原狀。
  • 查出節拍：右鍵點選波形 →「偵測節拍」，即可自動推算伴奏的 BPM。

10效果（FX）

可將殘響、壓縮器等外掛程式加到軌道或整體（master）。

開啟 FX 插槽

按下 TRACKS 面板左下的 FX 按鈕後，各軌道右側會顯示效果用的插槽（INS）。再按一次即可隱藏。

  • 點擊空插槽 → 選擇想用的外掛程式來加入。
  • 點擊已加入外掛程式的標籤，即可開啟設定畫面。
  • 用 Ctrl＋點擊可暫時關閉（旁通）。拖曳可重新排序或移到其他軌道（Alt＋拖曳則為複製）。
找不到外掛程式時：請開啟「檔案」→「管理外掛程式...」並執行掃描。已安裝的外掛程式會顯示在清單中。

加入殘響（Rev）

用各軌道的 Rev 滑桿，即可為該軌道加入殘響。也可只套用於錄音中的「回送（監聽）」，這種情況下不會寫入錄音檔案。

11匯入·手動編寫 MIDI

可匯入 MIDI 資料（.mid 檔案），作為導唱旋律、和聲或伴奏使用。也可用手動方式編寫。

匯入 MIDI 檔案

  1. 選擇「檔案」→「匯入 MIDI...」，開啟 .mid 檔案（也可拖放到時間軸上）。
  2. 在「匯入 MIDI」對話框中，勾選想匯入的軌道（會顯示各軌道的聲道與音符數）。
  3. 配置方式可從「配置於開頭」或「配置於目前播放位置」中選擇。視需要勾選「一併匯入節拍·拍號」「一併匯入標記」。
  4. 按下「匯入」後，選取的軌道會以 MIDI 軌道的形式加入。
要發出聲音：匯入的 MIDI 軌道會以內建音色播放。若插入你喜好的音源外掛程式，即可用該音色發聲（與效果（FX）相同的方式加入）。

手動編寫（製作和聲·導唱）

  • 從新增軌道選單中選擇「新增 MIDI 軌道」。
  • 雙擊時間軸即可建立編寫用的區段，雙擊該區段則會開啟鋼琴卷軸（鍵盤編輯畫面）。
  • 在鋼琴卷軸中，雙擊空白處可新增音符，拖曳可移動／變更長度，按 Delete 可刪除。用 ↑ / ↓ 可上下移動半音。

12匯出（WAV / MP3）

完成後匯出成音訊檔案。

  1. 開啟畫面右上的 EXPORT 按鈕，或「檔案」→「匯出...」（Ctrl+E）。
  2. 選擇格式（WAV / AIFF / MP3）與範圍（整首曲子／選取範圍／小節範圍）。
  3. 選擇是要把整個混音匯出成一個檔案，還是依軌道（分軌 stem）分開匯出。
防止破音：匯出時，若音量過大會自動稍微降低以防止破音（可在設定中關閉）。

15遇到問題時

顯示「找不到音訊檔案」

專案參照的音源可能被移動／刪除了。將原始檔案放回專案內的 Audio 資料夾，即可自動復原。

上次的作業不見了／應用程式結束了

重新開啟已儲存的專案時，若存在更新的備份，會詢問你是否復原。選擇「復原」即可回到先前的狀態。

錄不到麥克風的聲音

  • 確認作業系統的麥克風使用權限是否已允許 Utawave。
  • 在環境設定的音訊設定中，確認是否已選擇正確的輸入裝置與聲道。
  • 確認軌道的 R（錄音待命）是否已亮起。

自己的聲音聽起來有延遲（監聽延遲）

在 Windows 上使用音訊介面時，於音訊設定中將驅動程式種類選為 ASIO（介面隨附的驅動程式），可大幅改善。同時把緩衝大小調小也能減少延遲（若調得太小導致聲音斷續，請往回調一級）。

錄好的歌聽起來比伴奏慢

Utawave 會在錄音時自動補正裝置的延遲（latency）。若仍有偏差，請在環境設定的「錄音流程」中，將額外的錄音補正 (ms) 一點一點增加來調整（增加會往前移動）。

外掛程式沒有出現在清單中

請在「檔案」→「管理外掛程式...」執行「全部重新掃描」。剛安裝完的外掛程式也會被辨識。有運作問題的外掛程式會在掃描時自動排除（應用程式不會當掉）。
